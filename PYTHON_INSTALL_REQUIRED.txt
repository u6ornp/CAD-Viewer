⚠ CURRENT STATUS:
────────────────────────────────────────────────────────────────────────
Python is not actually installed on this system.

The "python" shortcut in Windows is just a Microsoft Store placeholder,
not a real Python installation.


✅ SOLUTION: Install Real Python
────────────────────────────────────────────────────────────────────────

1. Download Python from: https://www.python.org/downloads/

2. Click "Windows installer (64-bit)"
   (Get version 3.10 or 3.11, NOT 3.12+)

3. Run the installer and:
   ✓ Tick "Add Python to PATH" (IMPORTANT!)
   ✓ Tick "Install pip"
   ✓ Click "Install Now"

4. Wait for installation to complete (~1 minute)

5. Restart your terminal/command prompt

6. Verify installation:
   python --version
   (Should show something like: Python 3.11.0)

7. Then run:
   pip install pythonocc-core
